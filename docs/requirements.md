# 📑 [기획 명세서] SubGuard, 구독서비스 자동결제 알림 서비스

## 1. 프로젝트 개요 (Overview)

- **프로젝트명**: SubGuard(구독서비스 자동결제 알림 서비스)
- **배경 및 문제 정의**:
    - 최근 다양한 구독 서비스가 많아지면서, 사용자들이 구독 서비스를 제대로 관리하지 못해서 원치 않는 자동 결제로 불편함을 겪음.
    - 무료 체험 서비스 기간이 지난 후 자동 결제가 되지만 알림 서비스가 미흡해 알지 못하여 원치 않는 추가 결제로 불편함을 겪음.
- **목표**: 기존의 흩어진 구독 서비스를 달력뷰를 통해 한눈에 보고, 결제 임박 구독을 알려줌으로써 구독을 연장 또는 해지하여 불필요한 결제 및 환불 과정을 줄이도록 서비스를 제공함.

## 2. 핵심 기능 요구사항 (Requirements)

- **사용자 플로우**: 
    if 구글 계정으로 로그인한 경우 : 메인화면으로 이동
    else 로그인하지 않았을 경우 : 로그인 화면으로 이동 ➔ 구글 계정 로그인

    if 실시간 카운터 후, 등록된 구독 서비스 데이터가 있을 경우 : 메인 화면 유지
    else 실시간 카운터 후, 등록된 구독 서비스 데이터가 없을 경우 : 구독 서비스 등록하기 팝업창 ➔ 구독 서비스 등록하기 화면 ➔ 무료 체험 등록하기 화면/정기 구독 등록하기 화면 ➔ 등록 완료 화면 ➔ 메인화면으로 자동 이동

- **백엔드(Supabase) 연동**:
    - **메인화면 데이터 적재**: 구독 서비스 등록 시, 로그인한 계정의 구독 서비스 데이터에 저장
    - **실시간 카운터**: 메인 화면 진입 시, 로그인한 계정의 구독 서비스 데이터를 읽은 후, 메인 화면 캘린더뷰로 표현

## 3. UI/UX 와이어프레임 및 디자인 가이드

### 3-1. 메인 화면 (Home)

- **캘린더**:월~일 기준 월별 캘린더로 구독서비스 데이터를 표시하기. 캘린더에 표시된 데이터에 커서를 가져가면 '구독 서비스명', '결제 금액', '첫 결제 날짜', '결제 주기'를 띄워주고, 커서를 치우면 사라짐. 각 데이터를 클릭 시, 등록된 구독 서비스 상세 화면 팝업창으로 이동(각 구독서비스의 대표 아이콘 및 컬러를 적용, `↻ 이번 달` 버튼을 누르면 현재 날짜 캘린더로 돌아감.) 
- **타이틀**: "이번 달 구독서비스 관리" (가장 잘 보이도록 큰 글씨)
- **월별 구독료**: `이번 달 구독료`(이번 달 결제한 총 구독료 계산, 캘린더 오른쪽에 위치함. 각각의 구독 서비스 이름, 구독 서비스 결제 금액, 결제 날짜를 표시하고 맨 아래에 총 금액을 표시함. 각 서비스 클릭 시 해당 구독 서비스의 등록된 구독 서비스 상세 화면 팝업창을 띄움.)
- **결제 임박 구독 서비스 알림**: `곧 결제되는 서비스예요` (눈에 띄는 백그라운드 컬러 적용) 3일 내로 결제되는 서비스를(정기 결제, 무료 체험 모두 포함) 알려줌. 월별 구독료 하단에 위치함. 각 서비스 클릭 시 해당 구독 서비스의 등록된 구독 서비스 상세 화면 팝업창을 띄움.
- **무료 체험 종료 서비스 알림** : `무료 체험이 종료돼요` (붉은 주황색으로 긴급 알림표시) 3일 내로 무료 체험이 종료되는 서비스를 알려줌. 결제 예정 날짜 및 무료 체험 종료일 표시함. 결제 임박 구독 서비스 알림 하단에 위치. 각 서비스 클릭 시 해당 구독 서비스의 등록된 구독 서비스 상세 화면 팝업창을 띄움.
- **CTA 버튼**: `[새로운 구독서비스 등록 ➔]` (캘린더 우측 상단에 위치)
- **네비게이션 바** : '홈', '설정' 탭으로만 이루어짐. '설정' 탭 클릭 시, 현재 로그인한 계정의 정보 확인.(계정 정보 팝업은 메인 화면 영역까지 사용할 수 있음.) '설정' 탭 안에 로그아웃 아이콘이 있고, 아이콘 아래 작은 글씨로 로그아웃이라고 명시함. 로그아웃 아이콘 클릭 시, `로그아웃 하시겠습니까?` 로그아웃 확인 팝업창 띄우고 `로그아웃` 버튼 클릭 시 로그아웃, `취소` 버튼 누르면 팝업창 제거 후 메인 화면 유지.

### 3-2. 등록된 구독 서비스 상세 화면 팝업창

- 메인화면 위에 표시하는 둥근 사각형 팝업창, 그림자 표시, 우측 상단에 `X`로 닫기 버튼(닫기 버튼 클릭 시 팝업창 제거되어 메인 화면이 바로 보임.)
- 선택된 구독 서비스의 데이터를 바탕으로, '구독 서비스명', '결제 금액', '결제 주기', '첫 결제 날짜'를 표시함. 
- 무료 체험 구독 서비스 중 자동결제가 이뤄지지 않는 서비스는 '첫 결제 날짜' 대신 '무료 체험 종료일'로 표시함.
- 구독 서비스명을 메인 타이틀로 표시함.'결제 금액', '결제 주기'는 '편집'버튼을 누르면 수정할 수 있도록 함. ('결제 금액', '결제 주기' 수정 시 수정한 날짜 이전 데이터는 유지하고 수정한 날짜 이후 데이터만 수정함.)
- **CTA 버튼**: `삭제하기` 버튼 클릭 시,정말로 삭제할 것인지 더블체크하는 팝업창을 띄우고, 삭제 시 클릭한 날짜 이후로 구독 서비스가 캘린더에 뜨지 않음.(삭제 날짜 이전 데이터는 유지하여 표시함.)

### 3-3. 구독 서비스 등록하기 팝업창

- 메인화면 위에 표시하는 둥근 사각형 팝업창, 그림자 표시, 우측 상단에 `X`로 닫기 버튼(닫기 버튼 클릭 시 팝업창 제거되어 메인 화면이 바로 보임.)
- **CTA 버튼**: `등록하기` 버튼 클릭 시, 구독 서비스 등록하기 화면으로 이동
- 메인 화면 진입해서 실시간 카운터 후, 캘린더에 표시할 등록된 구독 서비스 데이터가 있을 경우 : 구독 서비스 등록하기 팝업창띄우지 않고 메인 화면만 유지. 
- 메인 화면 진입해서 실시간 카운터 후, 캘린더에 표시할 등록된 구독 서비스 데이터가 없을 경우 : 메인 화면 위에 구독 서비스 등록하기 팝업창 띄우기

### 3-4. 구독 서비스 등록하기 화면
- **타이틀** : "새로운 구독 서비스 등록하기"
- **서브 타이틀** : "등록하는 구독 서비스의 유형을 선택하세요."
- **CTA 버튼** : 버튼1 `무료 체험`, 버튼2 `정기 구독` (버튼1 클릭 시, 무료 체험 등록하기 화면으로 이동, 버튼2 클릭 시, 정기 구독 등록하기 화면으로 이동)

### 3-5. 무료 체험 등록하기 화면
- **타이틀**: "새로운 구독 서비스 등록하기"
- **서브 타이틀** : "무료 체험 등록"
- **구독 서비스 이름 입력창**: `구독서비스 이름을 입력하세요.`(사용자가 직접 입력할 수 있도록 함. 대한민국에서 가장 많이 사용하는 구독서비스 50가지를 데이터 셋에 저장하고 사용자가 입력하는 입력값과 비교하여 가장 유사한 구독서비스를 아래에 제시함. 사용자가 입력을 마쳤거나 입력창에 커서가 없으면 유사한 구독 서비스를 제시하지 않아도 됨.)
- **무료 체험 일회성 체크** : `무료 체험 기간 종료 후 결제 예정` (체험 기간 이후 자동 결제가 이루어지는지 버튼 클릭 True/False로 판단함. True일 경우, 무료 체험 서비스 결제 날짜 입력창과 무료 체험 서비스 결제 가격 입력창을 활성화 함. False일 경우는 무료 체험 서비스 기간 입력창을 활성화 함.)
- **무료 체험 서비스 기간 입력창** : `무료 체험 기간을 입력하세요.` (X일로 표현하며, X는 사용자가 입력할 수 있도록 함.)
- **무료 체험 서비스 결제 날짜 입력창** : `결제 예정 날짜를 입력하세요.` (사용자가 직접 입력하거나 캘린더에서 직접 선택할 수 있도록 함.)
- **무료 체험 서비스 결제 가격 입력창**: `결제 예정 금액을 입력하세요.` (사용자가 직접 입력할 수 있도록 함. 단위는 대한민국 원화이고 세자리마다 ',' 표시,예시: 10000 입력 -> 10,000원)
- **CTA 버튼** : `등록하기`버튼 클릭 시, 입력 값이 모두 입력되었는지 확인하고 입력 데이터를 데이터베이스에 저장 -> 저장 성공 시, 등록 완료 화면으로 이동 (저장 실패 시, 오류 메세지 출력 후 메인 화면으로 이동)

### 3-6. 정기 구독 등록하기 화면
- **타이틀**: "새로운 구독 서비스 등록하기"
- **서브 타이틀** : "정기 구독 등록"
- **구독 서비스 이름 입력창**: `구독서비스 이름을 입력하세요.`(사용자가 직접 입력할 수 있도록 함. 대한민국에서 가장 많이 사용하는 구독서비스 50가지를 데이터 셋에 저장하고 사용자가 입력하는 입력값과 비교하여 가장 유사한 구독서비스를 아래에 제시함.)
- **구독 서비스 결제 가격 입력창**: `결제 금액을 입력하세요.` (사용자가 직접 입력할 수 있도록 함. 단위는 대한민국 원화이고 세자리마다 ',' 표시,예시: 10000 입력 -> 10,000원)
- **구독 서비스 결제 날짜 입력창** : `결제 날짜를 입력하세요.` (사용자가 직접 입력하거나 캘린더에서 직접 선택할 수 있도록 함.)
- **구독 서비스 결제 단위 입력창** : `결제 주기를 입력하세요.` (X회 / Y로 표현하며 Y는 '월','년','주'를 드롭다운 형식으로 사용자가 직접 입력할 수 있도록 함. 처음 default는 1회/월로 표시하고 이후 사용자가 변경할 수 있음.)`
- **CTA 버튼** : `등록하기`버튼 클릭 시, 모든 데이터가 입력되었는지 확인하고 입력 데이터를 데이터베이스에 저장 -> 저장 성공 시, 등록 완료 화면으로 이동 (저장 실패 시, 오류 메세지 출력 후 메인 화면으로 이동)

### 3-7. 등록 완료 화면 
- **타이틀**: "등록이 완료되었습니다."
- **CTA 버튼**: `메인화면으로 돌아가기` 버튼 클릭 시, 메인 화면으로 이동

### 3-8. 로그인 화면
- 사용자가 구글 계정을 연동하여 로그인한다.
