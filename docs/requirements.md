# 📑 [기획 명세서] SubGuard, 구독서비스 자동결제 알림 서비스

## 1. 프로젝트 개요 (Overview)

- **프로젝트명**: SubGuard(구독서비스 자동결제 알림 서비스)
- **배경 및 문제 정의**:
    - 최근 다양한 구독 서비스가 많아지면서, 사용자들이 구독 서비스를 제대로 관리하지 못해서 원치 않는 자동 결제로 불편함을 겪음.
    - 무료 체험 서비스 기간이 지난 후 자동 결제가 되지만 알림 서비스가 미흡해 알지 못하여 원치 않는 추가 결제로 불편함을 겪음.
- **목표**: 기존의 흩어진 구독 서비스를 달력뷰를 통해 한눈에 보고, 결제 임박 구독을 알려줌으로써 구독을 연장 또는 해지하여 불필요한 결제 및 환불 과정을 줄이도록 서비스를 제공함.
---

## 2. 핵심 기능 요구사항 (Requirements)

- **사용자 플로우**: 
    if 구글 계정으로 로그인한 경우 : 
        if 이미 등록된 구독서비스가 있을 경우 : 메인화면에서 등록된 구독 서비스의 결제 날짜 확인
        else 등록된 구독서비스가 없을 경우 : 구독 서비스 등록하기 팝업창 ➔ 구독 서비스 등록하기 화면 ➔ 등록 완료 화면 ➔ 메인화면으로 자동 이동
    else 로그인하지 않았을 경우 : 로그인 화면으로 이동 ➔ 구글 계정 로그인

- **백엔드(Supabase) 연동**:
    - **메인화면 데이터 적재**: 구독 서비스 등록 시, 로그인한 계정의 구독 서비스 데이터에 저장
    - **실시간 카운터**: 메인 화면 진입 시, 로그인한 계정의 구독 서비스 데이터를 읽은 후, 메인 화면 캘린더뷰로 표현

## 3. UI/UX 와이어프레임 및 디자인 가이드

### 3-1. 메인 화면 (Home)

- **캘린더**:월~일 기준 월별 캘린더로 구독서비스 데이터를 표시하기 (각 구독서비스의 대표 아이콘 및 컬러를 적용) 
- **타이틀**: "이번 달 구독서비스 관리"
- **월별 구독료**: `이번 달 구독료`(이번 달 결제한 총 구독료 계산)
- **결제 임박 구독 서비스 알림**: `곧 결제되는 서비스예요` (눈에 띄는 백그라운드 컬러 적용) 3일 내로 결제되는 서비스 알려줌.
- **CTA 버튼**: `[새로운 구독서비스 등록 ➔]` (캘린더 우측 상단에 위치)

### 3-2. 구독 서비스 등록하기 팝업창

- 메인화면 위에 표시하는 둥근 사각형 팝업창, 그림자 표시, 우측 상단에 `X`로 닫기 버튼(닫기 버튼 클릭 시 팝업창 제거되어 메인 화면이 바로 보임.)
- **CTA 버튼**: `등록하기` 버튼 클릭 시, 구독 서비스 등록하기 화면으로 이동

### 3-3. 구독 서비스 등록하기 화면
- **타이틀**: "새로운 구독 서비스 등록하기"
- **구독 서비스 이름 입력창**: `구독서비스 이름을 입력하세요.`(사용자가 직접 입력할 수 있도록 함. 대한민국에서 가장 많이 사용하는 구독서비스 30가지를 데이터 셋에 저장하고 사용자가 입력하는 입력값과 비교하여   가장 유사한 구독서비스를 아래에 제시함.)
- **구독 서비스 결제 가격 입력창**: `결제 금액을 입력하세요.` (사용자가 직접 입력할 수 있도록 함. 단위는 대한민국 원화이고 세자리마다 ',' 표시,예시: 10000 입력 -> 10,000원)
- **구독 서비스 결제 날짜 입력창** : `결제 날짜를 입력하세요.` (사용자가 직접 입력하거나 캘린더에서 직접 선택할 수 있도록 함.)
- **구독 서비스 결제 단위 입력창** : `결제 주기를 입력하세요.` (X회 / '월'or'년'or'주' 형식으로 사용자가 직접 입력할 수 있도록 함. 처음 default는 1회/월로 표시하고 이후 사용자가 변경할 수 있음.)
- **CTA 버튼** : `등록하기`버튼 클릭 시, 모든 데이터가 입력되었는지 확인하고 입력 데이터를 데이터베이스에 저장 -> 저장 성공 시, 등록 완료 화면으로 이동 (저장 실패 시, 오류 메세지 출력 후 메인 화면으로 이동)

### 3-4. 등록 완료 화면 
- **타이틀**: "등록이 완료되었습니다."
- **CTA 버튼**: `메인화면으로 돌아가기` 버튼 클릭 시, 메인 화면으로 이동

### 3-5. 로그인 화면
- 사용자가 구글 계정을 연동하여 로그인한다.
